---

## Deploy no GitHub Pages

O deploy roda sozinho a cada push na `main`.

1. Vá em **Settings → Pages**  
2. Em **Source**, escolha **GitHub Actions**  
3. Faça push na `main`  
4. Acompanhe em **Actions** até ficar verde  

Pronto: o site sobe em  
`https://arthknov.github.io/Portfolio-Arthur-Lima/`
